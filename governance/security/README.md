# governance/security/

Weekly reports from the security agent (`ilorium-security-agent[bot]`, AI, Genome Law 5).

- One file per report: `YYYY-MM-DD-report-NNNN.md`, numbered from 0001.
- Content: dependencies, site headers, DNS, organization configuration. Tone: observed / not observed / recommended. No alarmism.
- Zero-write mode (decision 0002): the agent writes nothing to this repository. It opens an issue labeled `agent-authored`, `security` with the report. A human copies it here through a normal pull request. The agent never commits and never merges.
- Vulnerability details never appear here. Those go through private reporting (SECURITY.md) and Security Advisories.

Status: the weekly audit is planned until the founder configures the GitHub App. The first report, if present, was prepared during the initial deployment.
