## Recommended

In this order, by the founder, with his own account:

1. Register two hardware security keys on the founder's GitHub account; disable SMS fallback. Do the same for the Google Workspace superadmin before any group exists.
2. Create the organization; require two-factor authentication for everyone; set the base permission to Read; members cannot create repositories.
3. Verify `ilorium.com` in the organization (TXT challenge). This is the first defense against impersonation.
4. Enable, for all repositories: Dependabot alerts and security updates, secret scanning, push protection, private vulnerability reporting, code scanning (CodeQL). Set "Allow GitHub Actions to create and approve pull requests" to off.
5. Push the four repositories with the initial commits re-authored and signed by the founder; then import the two rulesets. The required status checks named in `main-protection.json` must match the job names observed above (`ci / docs`, `ci / verifier`, `dco`, `agent-readable-files`, `CodeQL`, `security-agent-review`); a mismatch blocks every merge.
6. Create the labels from `org/labels.json`.
7. DNS: DNSSEC on; CAA with `iodef` to security@; MX; SPF `-all`; DKIM from the Workspace console; DMARC `p=quarantine` with `rua`, then `p=reject` after two weeks of clean reports; the GitHub verification TXT.
8. Deploy the site; run `site/tools/check_headers.py https://ilorium.com`; confirm `security.txt`, `ilorium.json` and `llms.txt` are served; then submit HSTS preload.
9. Create the GitHub App `ilorium-security-agent` with the permissions table in `security-agent/README.md`; install it on the organization; set `SECURITY_AGENT_APP_ID`, `SECURITY_AGENT_PRIVATE_KEY` and `AGENT_SIGNOFF`. Run the weekly audit once by hand with `dry-run: true` and read the summary.
10. Turn on "Require actions to be pinned to a full-length commit SHA" once every workflow in every repository is pinned; `org/pin-actions.md` lists what is not.
11. Later: PGP key for security@ and a signature on `security.txt`; the model review key; the mailbox service account.
