# Conformity vectors (Apache-2.0)

384 cases in 13 files, generated by [`../tools/gen_vectors.py`](../tools/gen_vectors.py), which shares no code with the verifier. `index.json` lists every file with its operation, case count and SHA-256 (Evidence Format 1.0, section 15); `tools/vectors_index.py --check` verifies it in CI and before each release. Keys inside are **test keys only**. An implementation claims conformity with release 1.0 by passing every case: `ILORIUM_SCHEMAS=schemas ilorium-verifier conformity vectors`. Never edit a vector by hand.
